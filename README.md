# QuizMaster (Ire's copy)

A three-screen starter for a quiz app, written during a Techbase coding class.

## What it does

- **Home screen:** a welcome message and a Start Quiz button.
- **Quiz screen:** a question with four answer buttons and a Finish button. The question and options are placeholders; no real questions are loaded yet.
- **Result screen:** shows a score and a button back to the home screen. The score is a fixed test value of 3, not a calculated result.

It shows how to switch between screens with plain JavaScript by toggling an `active` class. It does not yet ask real questions, keep score or save anything.

## Run it

Open `index.html` in a browser. There is nothing to install.

## Files

```
index.html     The three screens
css/style.css  Layout and colours
js/app.js      Screen switching and the placeholder score
```
